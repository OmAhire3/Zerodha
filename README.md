## ✨ About The Project

**Zerodha Clone** is a full-stack web application designed to replicate the core experience of a modern online trading platform.

The project focuses on building a complete application where users can:

- 🔐 Create an account and login
- 📊 View their trading dashboard
- 💼 Manage holdings
- 📈 Track positions
- 🛒 Place buy and sell orders
- 📋 View order history
- 📉 Visualize data using interactive charts
- 👤 Manage their profile

This project was built as a hands-on learning experience with the **MERN stack**.

---

## 🎯 Key Features

### 🔐 Authentication
- User registration
- Secure login
- Password hashing using `bcrypt`
- User-specific dashboard experience

### 📊 Trading Dashboard
- Portfolio overview
- Holdings
- Positions
- Orders
- User profile
- Dynamic portfolio information

### 📈 Interactive Charts
- Visual representation of trading data
- Dynamic chart labels
- Chart.js integration

### 🛒 Order Management
- Buy orders
- Sell orders
- New order creation
- Order history

### 🗄️ Database
- MongoDB database
- Mongoose models
- Persistent user and trading data

### ☁️ Cloud Integration
- Cloudinary integration
- Render deployment support
- MongoDB Atlas database
