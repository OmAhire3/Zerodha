## ✨ Overview

**Zerodha Clone** is a full-stack trading platform created to understand and implement real-world web development concepts using the **MERN stack**.

The application includes a responsive landing page, user authentication, trading dashboard, portfolio management, order management, and interactive data visualization.

---

## 🔥 Features

- 🔐 **User Authentication**
  - User registration
  - Login functionality
  - Password hashing with bcrypt

- 📊 **Trading Dashboard**
  - Portfolio overview
  - Holdings
  - Positions
  - Orders
  - User profile

- 📈 **Interactive Charts**
  - Dynamic portfolio visualization
  - Chart.js integration
  - Dynamic chart labels and data

- 🛒 **Order Management**
  - Buy orders
  - Sell orders
  - New order creation
  - Order history

- 💼 **Portfolio Management**
  - Track holdings
  - Track positions
  - View portfolio information

- 🎨 **Responsive UI**
  - React-based components
  - Bootstrap styling
  - Responsive layouts

- 🧪 **Testing**
  - Jest
  - React Testing Library
  - jest-dom

- 🗄️ **Database**
  - MongoDB
  - Mongoose
  - MongoDB Atlas
